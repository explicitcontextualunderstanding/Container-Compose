### Step 3: Add Static Tests for Recovery Logic (Red)

- `testRecoveryPurgesZombieRestarting()` - verify restarting state triggers purge/recreate
- `testDriftWarningEmitted()` - verify `[DRIFT WARNING]` when image differs from compose.yml

### Step 4: Implement Recovery Logic (Green)

**File**: `Sources/Container-Compose/Commands/ComposeUp.swift`

Modify `configService()` method (lines 676-823):

1. **Gate existing container logic with `recover` flag**:
   - Current: Lines 764-786 run unconditionally
   - Change: Only run recovery logic when `recover == true`
   - Non-recovery mode: Continue to error on existing containers

2. **Implement state-based decision matrix** (when `recover == true`):
   | State      | Action           | Log Message                          |
   |------------|------------------|--------------------------------------|
   | `running`  | Skip             | "[RECOVER] Skipping {name} - already running" |
   | `exited`   | Start            | "[RECOVER] Starting {name} - was stopped" |
   | `creating` | Purge + Recreate | "[RECOVER] Purging zombie {name} - state: creating" |
   | `dead`     | Purge + Recreate | "[RECOVER] Purging zombie {name} - state: dead" |
   | `restarting`| Purge + Recreate | "[RECOVER] Purging zombie {name} - state: restarting" |
   | Missing    | Create new       | "[RECOVER] Creating {name} - not found" |

3. **Add `[DRIFT WARNING]`** when `recover == true`:
   - Compare `existingContainer.image` with `service.image`
   - Compare `existingContainer.environment` with `combinedEnv`
   - Log: "⚠️ [DRIFT WARNING] Container '{name}' image differs from compose.yml"

**New Helper Methods**:
- `checkContainerDrift(existing: ContainerInfo, service: Service, env: [String:String]) -> [String]`
- `purgeZombieContainer(name: String) async throws`

### Step 5: Add Dynamic Tests for Recovery (Red)
